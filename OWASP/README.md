# OWASP Walkthroughs (Beginner-Friendly Index)

This folder contains structured TryHackMe OWASP Top 10 2025 writeups.

## Recommended Reading Order

1. [`1.md`](./1.md) — IAAA Failures  
   Covers broken access control, authentication failures, and logging/alerting failures.
2. [`2.md`](./2.md) — Application Design Flaws  
   Covers misconfiguration, supply chain, cryptographic, and insecure design flaws.
3. [`3.md`](./3.md) — Insecure Data Handling  
   Covers weak crypto, SSTI injection, and insecure deserialization.

## Folder Notes

- All screenshots used by these writeups are kept in this same `OWASP/` folder.
- Utility scripts for challenge solving are also in this folder (`dec.py`, `des.py`).
- Duplicate/legacy combined writeups were removed to keep navigation clear.

## Quick Tip for Beginners

For each writeup, read sections in this order:
1. **Challenge overview/question**
2. **Step-by-step solution**
3. **Evidence screenshot**
4. **Key takeaway**
